Connection & metric notes

Use an address reachable from this browser. “localhost” refers to this computer. When the API uses a different origin, it must allow this page through CORS. Same-origin deployment needs no extra CORS configuration.

TTFT is client-observed time from request start to the first non-empty text or reasoning delta. Role-only chunks do not count.

Token rate is cumulative output tokens ÷ elapsed request time, including TTFT and network time. It is not server-only decode throughput.

Without usage, tokens are estimated as Unicode characters ÷ 4, including reasoning. This can be inaccurate, especially for non-English text and code. SSE chunks are never counted as tokens.

Server usage replaces the estimate when available. Continuous usage is a vLLM extension. No settings, keys, or conversations are saved by this page.
